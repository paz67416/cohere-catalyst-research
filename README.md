# Cohere Catalyst Research

所有感（sense of ownership）・主体感（sense of agency）・フロー状態の事後性仮説に関する研究記録。Cohere Labs Catalyst Grant の支援を受けています。

## 研究の概要

本研究は、フロー状態における「身体が勝手に動いた」「自分がやっている感じが薄かった」という報告に含まれる非対称——主体感が後退しても、その行為はなお自分の経験として保持される——を出発点としています。

これを主体感と所有感の**形成時間の差**として定式化し、フロー状態では行為が先に成立し、行為所有感がこれに続き、主体感がさらに遅れて統合されるという二段階の遅延構造（「二重の事後性」）が主観的に前景化する、という仮説を提示しています（前景化仮説）。

理論的背景として、体験の成立からクオリア形成・クオリア取得へと至る三段階の媒介構造「Beral layer」を用いています（AIP Advances 16, 045126, DOI: [10.1063/5.0325944](https://doi.org/10.1063/5.0325944)）。

この枠組みは、Human-AI Interaction および AI Alignment 研究における agency・autonomy・qualia の構造的定義の空白とも接点を持ちます。

## 資料の位置づけについて

このリポジトリには、理論的主張の根拠として用いている文献と、**仮説形成の段階で用いた一人称観察の記録**が混在しています。両者の役割は異なります。

- **理論論文の根拠**は、第三者が測定・報告した先行研究に限定しています
- **睡眠境界観察ログ**および自己観察に由来する記述は、仮説形成と測定項目の検討に用いた材料であり、理論的主張を支える証拠としては使用していません

単一の著者による回顧記録には、証拠としての限界があります。自己観察を研究データとして扱うには、前向きな記録・固定した基準・独立した評価方法が必要であり、その条件の検討は理論論文とは別に進めています。

`docs/research-report.md` は 2026年7月時点の版です。原稿はその後、証拠構成の全面的な組み替えを経ているため、現時点の主張については Zenodo 版（[10.5281/zenodo.21771960](https://doi.org/10.5281/zenodo.21771960)）を参照してください。

## 文献の取り扱い

文献レビューでは、以下の段階を区別しています。

1. 題名・要旨による候補抽出
2. 全文による論点と方法の確認
3. 引用箇所と原文の照合
4. 根拠文献としての採用

要旨は候補抽出には用いますが、理論上の根拠として採用する判断は全文確認後に行います。書誌情報は RAG や生成結果ではなく Crossref で照合し、識別子を基準に管理しています。
